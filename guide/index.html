MIT AI Risk Brand Guide

Visual identity for the AI Risk Initiative and its two named sub-products — the AI Risk Repository and the AI Risk Index. One shared icon, one type family, one palette, three product wordmarks.

1 · Logo

The primary mark is the Initiative horizontal lockup: the AIRI icon beside the two-line wordmark "MIT AI Risk / Initiative". Use this everywhere the brand needs a full name — navigation bars, document headers, hero sections.

Files: skill/logos/initiative/horizontal*.svg (and .png, 512 px tall). Text is rendered as outlined SVG paths, so the logo files have no font dependency. Lockup proportions are locked — the gap equals one "large square" in the icon, and the text is sized to span two medium squares.

2 · Icon

The icon is the "plus of squares" mark, shared by all three products. Use it on its own for favicons, app icons, small nav contexts, and anywhere the wordmark would be illegible.

4 · Sub-project lockups

Two sub-products have their own horizontal lockups. They share the icon and the first line of the wordmark with the Initiative; only the second line changes. Use the matching folder when you're specifically branding an Index or Repository surface. When in doubt, fall back to the Initiative lockup.

5 · Open questions

Internal notes on proposed extensions from the March 2026 website mockup project. Not part of the current brand — discuss with Jess before acting on any of these.

proposed Extended colour palette for data visualisation

The current 4-colour palette (red, rose, gray, dark) is insufficient for charts with 5+ series or image sets needing distinct identities. A ColorBrewer Set2-influenced secondary palette (teal / coral / blue / green / lavender / sand) has been prototyped.

Key question: Should these become formal brand colours with CSS tokens, or a recommended supplementary palette without token status? Either way, it changes the current "do not introduce additional brand colours" rule.

proposed Image and illustration style guide

The brand spec has no guidance on imagery. Proposed philosophy: abstract geometric and mathematical art (tessellations, network graphs, Voronoi diagrams), with each AIRI tool getting a signature visual motif. No text in images, no photorealism, no AI-generated faces. Photography only for headshots.

Key question: How prescriptive should the pattern-to-tool mapping be? Strict rules ensure consistency; loose guidance allows flexibility.

under review Additional web component patterns

Proposed additions: stats bar (primary numbers, gray labels), carousel with scroll-snap, greyscale partner logo display, blockquote testimonials, alternating section backgrounds. All emerged as necessary during the website mockup.

Key question: Do these belong in the brand spec or a separate design system doc?

out of scope Findings belonging to a content/UX doc

Tone of voice, CTA strategy by audience, data-freshness labelling — emerged from persona reviews but belong in a separate content and UX guidelines doc, not the brand.

More detail: skill/BRAND.md has the full specification, including component patterns (buttons, cards, tables, charts). CONTRIBUTING.md explains how AI coding assistants should apply the brand to new artefacts.
