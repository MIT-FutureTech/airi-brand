# AIRI Image Generation Style Guide

## Visual Philosophy
Images for the AIRI site should evoke the structured, analytical nature of risk research — patterns that suggest interconnection, complexity, and systematic categorization. They should feel like looking at the hidden mathematical structure beneath AI systems and their societal impacts.

## Style Description (for image generation prompts)

### Core Aesthetic
Abstract geometric and mathematical art. Tessellated patterns, network graphs, Voronoi diagrams, topological surfaces, and lattice structures. Clean, precise, almost architectural — like a visualization of an abstract risk space or taxonomy tree rendered as fine art.

### Mood
Serious but elegant. Academic gravitas with visual sophistication. Not cold or clinical — more like the beauty found in mathematical structures. Think: generative art exhibitions, data-driven installations, the visual language of complexity science.

### Color Palette
Extended from AIRI brand, influenced by ColorBrewer Set2 qualitative palette for variety:

**Primary tones** (from AIRI brand):
- MIT Red: #A32035 (use sparingly as accent, not dominant)
- Dark: #1A1A1A (for contrast elements)
- Warm gray: #898A8D

**Extended palette** (Set2-influenced, for variety across images):
- Soft teal: #66C2A5
- Warm coral: #FC8D62
- Muted blue: #8DA0CB
- Soft green: #A6D854
- Lavender: #E78AC3
- Sand: #E5C494
- Rose: #D07886 (from AIRI primary-light)

**Backgrounds**: Off-white (#FAFAFA), very light warm gray, or deep charcoal (#1A1A1A) for dark variants.

### Pattern Types (by usage)

1. **Hero/Banner**: Large-scale tessellation or network graph. Flowing, expansive. Should suggest breadth and interconnection. Light background with colored nodes/edges.

2. **Card Thumbnails**: Tight, focused pattern crops. Each card gets a distinct pattern type:
   - Repository → Dense lattice/grid (structured knowledge)
   - Incident Tracker → Branching/fractal pattern (cascading events)
   - Governance → Overlapping circles/Venn (jurisdiction overlap)
   - Mitigations → Shield/hexagonal tessellation (protection)
   - Blog/Research → Flowing curves/wave interference (emerging knowledge)

3. **Section Backgrounds**: Very subtle, low-opacity pattern overlays. Should not compete with text.

### Technical Specs
- Aspect ratio: 16:9 for cards, 3:1 for banners
- Resolution: High enough for 2x displays
- No text in generated images
- No photorealistic elements
- No AI-generated faces or figures

### Prompt Template
```
[Pattern type] abstract mathematical art, [specific pattern description],
using colors [hex codes], on [background color] background,
clean geometric precision, generative art style, no text,
high resolution, minimal and elegant
```
